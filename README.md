# Kunal Kushwaha - Portfolio

Professional Portfolio Website of **Kunal Kushwaha** — AC & Mechanical Technician.

![Kunal Kushwaha Portfolio](public/image.png)

## 📌 About
A hardworking and responsible technician with practical expertise in:
- AC Installation, Servicing & Gas Charging
- HVAC Systems & Ducting
- Mechanical Repair & Preventive Maintenance
- Tools, Gauges & Workshop Equipment Handling

## 🚀 Features
- **Modern Glassmorphic Dark UI**: Vibrant neon accents, gradient borders, and sleek styling
- **100% Fully Responsive**: Pixel-perfect layout across desktops, laptops, tablets, and phones (down to 320px)
- **GSAP & ScrollTrigger Animations**: Smooth reveal animations, counting stats, and interactive transitions
- **Particle System**: Interactive background canvas with floating connected nodes
- **Dynamic Typing Headline**: Highlighting core technical competencies
- **Direct Contact Integration**: Click-to-call, mailto, and direct WhatsApp links

## 🛠️ Tech Stack
- **Structure**: HTML5
- **Styling**: Vanilla CSS (Custom properties, Glassmorphism, Fluid Typography)
- **Interactivity**: Modern JavaScript (ES6+)
- **Libraries**: [GSAP 3](https://greensock.com/gsap/) with ScrollTrigger, [Font Awesome 6](https://fontawesome.com/)

## 🌐 Deployment
This portfolio is ready for one-click deployment on [Vercel](https://vercel.com/) or GitHub Pages.
